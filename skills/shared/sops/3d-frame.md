# SOP: 3d-frame —— 3D 建系 + 顶点阵

触发：所有立体几何题（MODE: 3D 之后第一步）。

片段（正方体/长方体：棱长 2、原点起建最简）：
```
MODE: 3D
A = (0, 0, 0)
B = (2, 0, 0)
C = (2, 2, 0)
D = (0, 2, 0)
A1 = (0, 0, 2)
B1 = (2, 0, 2)
C1 = (2, 2, 2)
D1 = (0, 2, 2)
```

变体：
- 一般棱锥：让底面多边形尽量多的顶点落在坐标轴/坐标面上再写顶点阵；
  底面用 Polygon 建出（closed-region 卡）。
- 棱台：上底顶点按下底按比例缩放平移，逐点写精确坐标。
- 顶点命名沿用题目字母（含下标 A1、B1），与题面一一对应。

注意：
- 顶点坐标全部手写精确整数/分数（建系时选好原点让它们成为整数），不要出现无理数小数。
- 每个顶点跟 fixed-point 卡三件套 + 蓝色，可以顶点全列完后统一补属性行。
- 高度方向用 z 轴，别把题目里的"高"错映射到 x/y。
