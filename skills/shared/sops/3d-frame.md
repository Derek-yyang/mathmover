# SOP: 3d-frame — 建系与保留几何关系的顶点阵

适用：需要明确顶点的多面体题；球/圆锥等不必先造正方体顶点阵。
前置：从题给长度、角度、垂直关系确定基准点和方向，不根据透视图猜真实长度。

片段：长方体三条互相垂直的边向量 vx/vy/vz 与基点 A 已由题意给定。
<!-- example: frame-prism -->
```ggb
B = A + vx
D = A + vy
C = A + vx + vy
A1 = A + vz
B1 = B + vz
C1 = C + vz
D1 = D + vz
```

片段：直棱锥的顶点正投影 H、高 ht 与单位法向 nAxis 已确定。
<!-- example: frame-pyramid -->
```ggb
S = H + ht*nAxis
```

边界：
- 正方体还要求三个边向量等长；一般棱柱的侧棱向量可倾斜，不能强制 vz 竖直。
- 棱台上底来自同一锥顶按统一比例的相似缩放，不能各顶点任意平移；保留对应关系。
- 选最简局部坐标，但允许精确根式。一般几何体无法都变成整数坐标；不可改比例凑整数。
- 点名与边界顺序沿用题目；左右方位按原图对应，不用镜像替换。最终相机显示另由应用控制。
检查：所有边长、夹角和上下底对应满足题意；不要重复 MODE；驱动参数变化后顶点关系不破坏。
