# SOP: moving-point-function — 自变量驱动的动点

适用：题目指定横坐标参数，或动点沿 y=f(x) 运动。前置：f 已定义，确认变量范围及单位。

<!-- example: motion-function -->
```ggb
t = Slider(-1, 2, 0.05)
SetValue(t, 0.5)
P = (t, f(t))
ShowLabel(P, true)
SetLabelMode(P, 1)
SetColor(P, "Red")
Q = (t, 0)
segPQ = Segment(P, Q)
```
[-1,2]、步长和初值仅为演示；Q 仅用于题意确实要求向 x 轴投影时。

边界：
- 数学范围、演示窗口和初始值分别决定。开区间不能取端点；闭区间允许端点，退化时保留正确状态，不自动“留余量”。
- 无界范围用有限演示窗口并保持公式正确；不宣称滑块穷尽整个定义域。间断点需分段或有条件显示派生对象。
- 多个动点若有关联应共用参数并保留关系；只有独立自由度才增加独立滑块。
- 竖直线、不能表示为单值 y=f(x) 的曲线，使用路径/参数式，不硬套横坐标模式。
- 二维曲线参数 (x(t),y(t))、三维 (x(t),y(t),z(t)) 均可按题意表达；t 不一定是横坐标。
检查：低/中/高参数时 P 始终满足曲线和范围条件；关联点随动；不 SetFixed 驱动点。
