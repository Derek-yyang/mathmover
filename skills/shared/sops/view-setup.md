# SOP: view-setup —— 画布开场（视图模式 + 坐轴网格）

触发：所有题目，指令流第一块。

片段（2D）：
```
MODE: 2D
SetAxesVisible(true, true)
SetGridVisible(true)
```

片段（3D）：
```
MODE: 3D
```

变体：
- 立体几何一律 `MODE: 3D`，2D 视图命令不要出现在 3D 指令流里。
- 3D 题如需 2D 平面视图（截面题），保留默认双视图即可，不要额外命令。

注意：
- `MODE:` 行必须是第一行，后端解析器和前端渲染都依赖它。
- 坐轴/网格只开场设一次，不要在每个对象后重复设置。
