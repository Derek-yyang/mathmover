# SOP: locus —— 轨迹显式化（Locus 画答案）

触发：题目出现"轨迹 / 踪迹 / 求点 P 的路径 / 包络 / 观察…的形状"。

片段（参数滑块驱动的轨迹）：
```
locP = Locus(P, t)
SetColor(locP, "Red")
```

片段（轨迹是直线段时的轻量替代）：
```
locP = Segment(M1, M2)
SetLineStyle(locP, 2)
SetColor(locP, "Red")
```

变体：
- Locus 第二参必须是驱动动点的那个滑块（或路径参数），不是动点本身。
- 轨迹是圆/圆弧：可解析推出时直接 `Circle` / `Arc` 承载，比 Locus 更稳。

注意：
- 轨迹是这道题的"答案"，永远画成醒目色（Red）实体对象——轨迹不许只留在想象里，
  这是视觉完整度判分最常见的缺口。
- Locus 与路径对象并存时：路径（舞台）灰虚线，轨迹（答案）红实线，两种颜色不要混。
