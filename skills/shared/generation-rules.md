# 共同输出约定

- 第一行只写专家指定的 MODE，其后每行一条可执行指令。只用所提供的输入栏命令和合法签名；不输出解释、注释、代码围栏、占位符、省略号、伪循环或 Text 题面文字。
- 所有 2D 题默认开启主视图网格，开场显式输出 ShowGrid(1, true)。只有用户明确要求隐藏网格时才关闭；不因题型、纯几何或画面简洁自行关闭。坐轴按题意设置，与网格分别处理。
- 题干及各小问的绘图对象逐一建立，沿用题目点名。先定义后引用，属性紧随定义；复用已有输入，不覆盖上游对象。辅助对象用描述性名称，避开参数、题目标号和 Polygon 自动边名。
- 题给常量用精确分数/根式；能确定的参数先确定。讨论参数与独立运动按真实自由度控制，关联对象共用驱动。不为套示例添条件、改比例或缩运动范围。
- 独立定点锁定并显示标签；派生点用关系表达式，不能抄当前坐标；驱动点不锁定。路径、区域、立体内部运动分别保留一维、二维、三维自由度。
- 主体清楚显示，驱动点红色、关系点蓝色；解释性辅助保留，纯计算对象按目标视图隐藏。主线实线、辅助线灰虚线，填充适度透明。
- SOP 是具体写法参考，不是必须执行的题型流程。示例名称、数值、区间均按本题替换，只取需要的片段；未附的写法可依据允许命令自行构造，不补造无关对象。
- 输出前核对对象清单、定义依赖、类型/数量、分支和题给关系，推演关键参数及允许边界状态。数学范围、展示窗口和初始位置分开；不声称做过未执行的引擎验证。
