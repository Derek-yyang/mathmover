# 共同输出约定

- 第一行写指定 MODE，其后每行一条合法输入栏指令；不输出解释、注释、代码围栏、占位符、省略号、伪循环或 Text 题面文字。
- 2D 开场显式 ShowGrid(1, true)，仅用户明确要求时关闭；坐轴按题意独立设置。
- 先定义后引用，属性紧随定义；复用输入，不覆盖上游对象。辅助名称避开题目点名、参数和自动生成对象名。
- 常量用精确分数/根式；可确定的量先求出，关联对象引用共同驱动或上游关系，不抄当前坐标。**只有独立定点**锁定并显示标签（`SetFixed(A, true)`），驱动点不锁定；**派生点绝不能 `SetFixed`**（`B = A + vx`、`M = Midpoint(B, C)` 这类）——实测它会把表达式换成当前坐标常量、切断与上游的依赖，之后改上游它就不动了。
- 主体清楚显示。线/线段/圆/圆锥曲线**默认就是黑色实线、线宽 5**（够用，不必调）——不要写 `SetColor(..., "Black")`、`SetLineStyle(..., 0)`、`SetLineThickness(..., 5)` 这类"回默认或在默认值上打转"的样式行（纯空转，白占指令数）；要写的只有非默认的：驱动点红色、关系点蓝色、辅助线灰虚线。保留解释性辅助，隐藏纯计算对象，填充适度透明。
- 立体图形的线框一律「建系 → 具名顶点 → 逐条线对象连真实棱」（写法取 `3d-frame` / `3d-edges` 卡），**不要用 `Cube` / `Prism` / `Pyramid` / `Tetrahedron` 一步到位**——它们画得出线框，却给不出可引用的棱对象：下一轮要在这条棱上加动点、求交或作截面时只能推倒重来。
- SOP 仅供具体写法参考，按本题替换名称、数值和范围，只取所需片段；未附写法可用允许命令构造，不为套示例添条件、缩范围或增加对象。
