# 通用 GGB 写法

以下写法每题必用，直接照写；不确定的命令名以「严格语法约束」清单为准。

- **MODE 行**：第一行只写一次，`MODE: 2D`；立体几何题写 `MODE: 3D`。
- **视图**：`ShowAxes(1, true)` 开坐轴、`ShowGrid(1, true)` 开网格（2D 开场默认开网格，仅用户明确要求隐藏时才写 false；坐轴按题意独立设置）。视图 1/2/3 分别对应两个二维视图与三维视图；`SetVisibleInView(obj, 视图, false)` 按视图隐藏纯计算对象，`-1` 不等于视图 3。
  - **三维视图（3）的开场由宿主给：坐轴默认开、网格默认关**。别为了「画面干净」去写 `ShowAxes(3, false)` / `ShowGrid(3, false)`——用户会把没有坐标轴当成画坏了（2026-10-19 实测报过：同一个「画一个正方体」两次生成，一次留轴一次关轴，用户看到的就是「有时候坐标轴没了」）。只有用户明确要求隐藏坐轴/开网格时才写这两行。
- **点**：`A = (sqrt(3), -1/2)`，常量写精确分数/根式，不写小数近似；三维点写 `(x, y, z)`。独立定点用 `SetFixed(A, true)` 锁定，驱动点不锁定。派生点保留原表达式（如 `M = Midpoint(B, C)`），不能把当前坐标抄成常量。
  - **三维视图里没有滑块**：`Slider(...)` 是**二维视图**的控件，产品在 3D 课件里只显示三维视图——实测 `t = Slider(0, 1, 0.01)` + `M = Point(路径, t)` 下发后，`t` 虽然在对象表里、值也对，画面上**没有任何可拖的控件**，动点等于被冻住（用户 2026-10-20 报的「3d 视图下没有滑块」）。**3D 的动点一律写成路径点** `M = Point(路径)`，把参数交给用户**直接在图上沿路径拖**；`Slider` 只在 2D 稿子里用。三维里要一个连续变化的量，就让它挂在路径/曲线上，而不是挂滑块。
- **线**：`Segment(A, B)` 有限线段、`Line(A, B)` 无限直线、`Ray(A, B)` 单向射线、`Vector(A, B)` 向量——按题意选，别把有限画成无限。
- **标签**：`ShowLabel(A, true)` 显示标签，`SetLabelMode(A, 1)` 名称与值（按展示要求替换模式）。
- **样式**：`SetColor(f, "Red")` 颜色、`SetLineStyle(f, 2)` 虚线、`SetLineThickness(f, n)` 线宽、`SetPointSize(A, n)` 点大小、`SetFilling(poly, 0.3)` 填充透明度。**默认值不要写**：线/线段/圆/圆锥曲线默认**黑色实线、线宽 5**（粗细合宜，不必调）；点与函数另有自己的默认色，要改色才写。按约定需要写的只有驱动点 Red、关系点 Blue、辅助线 Gray + 虚线。
- **3D 取景**：`CenterView((x, y, z))` 定画面中心、`SetViewDirection((x, y, z))` 定观察方向（`SetViewDirection()` 回默认朝向）、`ZoomIn(倍率)` 是**相对当前的倍数**（>1 放大、<1 缩小；**绝不给负值**——负值会把缩放写成负数，画面直接报废）。**取景起点由宿主给，而且是每一轮都给**：这一轮下发的命令里只要出现**任何一条取景行**（`CenterView` / `SetViewDirection` / `ZoomIn`），宿主就先让相机回标准视域（约 ±9 单位）再执行 ⇒ 倍率一律按标准视域估（棱长 1 的图形通常 `ZoomIn(5~10)`），跟上一轮停在哪儿无关。由此两条规矩：**要动就三条一起动**——后续轮次想调视角，`CenterView` / `SetViewDirection` / `ZoomIn` 必须一起重发；只发其中一部分，没发的那部分会退回标准值（实测：加动点那轮只重发了 `CenterView`+`SetViewDirection`、漏掉 `ZoomIn(1.8)`，画面就从 1.8 倍缩回 1 倍）。**完全不想动视角就一条都别写**，相机会原样保持。图形太小或太大都是缩放的事，别拿朝向去救。
- **规矩**：以上都是输入栏命令，不是 JavaScript API（`setAxesVisible`、`setColor` 之类一律不能写入指令流）。属性行写在该对象定义之后，先定义后引用；名字避开题目已用名。
