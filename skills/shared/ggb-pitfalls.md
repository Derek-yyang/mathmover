# GeoGebra 生成时的执行注意

- 对象类型按具体重载处理：Root 返回点，不能包成 (Root(...),0)；需要横坐标用 x(E)。函数与圆锥曲线接口不同，多结果先承接再选取，不能虚构索引参数。
- 求交/求根失败会产生未定义对象并影响下游。先判断存在条件和数量；相切不取第二点，平行/重合不造唯一交点。索引从 1 起，不承诺左右/上下或另一点。
- 定义必须先于引用与属性；Polygon 自动生成边及小写名称，避免后续参数/辅助对象撞名。已有输入对象不得被其派生结果覆盖。
- 输入栏命令与 JavaScript API 分开：坐轴/网格用 ShowAxes/ShowGrid，标签用 SetLabelMode，线宽用 SetLineThickness，平行平面用 Plane(点,平面)。视图命令的三维编号为 3，SetVisibleInView 为 -1。
- 属性返回 false 或构造返回标签均不能单独证明执行成败。若实际检查引擎，应核对对象存在、值有效、点坐标有限以及关系/属性状态；未运行时只做构造推演，不声称验证通过。
