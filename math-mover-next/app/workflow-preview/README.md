# 工作流镜头预览

首页标题与下载入口下方继续保留原有可操作 HeroDemo 工作台；滚动驱动的题型选择演示放在能力条之后，替换原先“换一个角度，看懂一个问题”的独立案例区。开发服务启动后，仍可访问 `/workflow-preview` 单独预览；该独立路由仅开发环境可用。两处共用 `components/landing/WorkflowDemo.tsx`、样式和时间轴。

开场保持一个居中的真实输入框，左侧同时展示三张可选题图。默认选中解析几何，也可以点击函数或立体几何；演示指针会停在当前题图上，继续滚动后才开始拖入。三套选择分别使用 `problem.png`、`function.png` 和 `solid.png`，对应椭圆动点、抛物线与动点、正方体中的受约束动点三种构造，切换时会重建画板并播放各自回复与拖动观察。

镜头从同一个真实 `AssistantChatComposer` 拉远到固定 1920 × 1080（16:9）的工作台：256px 侧栏、384px 对话区，其余为画板。两侧合计占工作台宽度的三分之一。工作台保持固定比例，按可用空间等比缩放，避免较宽窗口将画面拉扁。工作台尺寸由 `WorkflowDemo.tsx` 统一控制，镜头缩放不更改组件本身的字号、间距、圆角。拉远期间使用 transform 保持平滑，结束后对齐平移像素并释放持续合成提示，让浏览器重绘最终比例；保持 GeoGebra 原有的坐标与鼠标命中方式。

滚动演示为独立全宽区域，固定镜头避开顶部导航栏；滚动进度和步骤跳转均按演示在文档中的实际位置计算。可通过右上角“跳过演示，查看模型接入”直接进入并聚焦后续配置区。原先“换一个角度，看懂一个问题”的独立案例区由这套演示替换，之后依次为模型接入、常见问题与下载。演示样式限定在 workflow-host 内，工作台不继承首页的按钮、正文排版覆盖；亮暗主题使用产品颜色变量。动态加载占位共用时间轴的滚动高度，避免加载后内容位置发生偏移。

播放顺序：拖入题图 → 输入完成并短暂停顿 → 拉远到完整工作台 → 镜头稳定后鼠标移到发送按钮并点击 → 工具调用与逐步构图 → 流式回复 → 阅读停顿 → 拖动 P 展示联动 → 松开并停留。拉远期间保留输入文字和附件，发送后才清空输入框、显示消息和工具过程。

完整回复输出后增加约 43.5vh 的阅读停顿，再让鼠标从对话区移到真实画板上的 P，悬停、握住，沿 x=6 将 P 从 (6,2) 平滑拖至 (6,0.8)。通过 GeoGebra 的 setCoords 更新真实约束点，C、D 与 CD 由原有几何依赖实时重算；指针位置从真实视图范围与画布位置换算。松手后指针移开、淡出，另留约 34.8vh 观察停顿。原有阶段长度保留，底部增加“拖动观察”入口，倒回滚动会还原对应点位。结束后不再持续写入点坐标，保留用户手动拖动；减少动态效果时直接显示静态结果。

全局展开后单独留出约 32vh 的滚动停顿，期间镜头、输入内容保持静止；之后鼠标出现、移动到发送按钮，变成小手并悬停半拍，再完成点击。按钮前悬停另占约 14.5vh，手指落点在切换样式和按下时保持对齐，按钮使用真实悬停色。鼠标移动和按下各增加一倍的滚动距离，整体演示随之延长，其他阶段保持原有节奏。步骤按钮通过同一时间映射跳转。

开场拖入沿缓弧加减速移动，鼠标保持抓取位置；输入框逐渐展开附件空间，题图收拢为真实 64px 缩略图后再交接。开场滚轮进度有轻量平滑，减少滚轮步进造成的顿挫；减少动态效果时直接显示附件。

打字阶段使用真实输入框的原生光标，并随文字移动到末尾；输入完成后的短暂停顿保留光标，拉远时隐藏。输入区间由 0.15–0.26 延长为 0.15–0.29，增加约 27% 的滚动距离，后续拉远、发送和构图相应顺延。

只有拉远镜头期间启用持续合成提示；开场、打字和完整工作台停留时均释放合成层，并对齐镜头平移像素，避免放大的输入文字和图标持续使用动画纹理而发虚。

直接复用的产品组件：

- `AssistantChatComposer`、`ComposerModelPicker`：输入、附件、模型与发送状态。
- `UserMessage`、`AssistantMessage`、`AgentExecutionProgress`：消息、工具过程与流式 Markdown。
- `ThreadListSidebar`、`ThreadList`：侧栏容器与课件列表。
- `ControlDeck`、`CanvasStage`：工具栏与实际 GeoGebra 引擎。

预设消息和工具事件仅用于演示，不请求真实 Agent、不保存课件。几何构造在本页独立的 GeoGebra 实例中执行。题图原样来自 `测试题目图片/高中题/椭圆3.png`。

演示画板固定二维与三维视角：禁用缩放、画布平移、旋转和标签拖动，滚轮继续滚动首页。仅 P 点允许选中和原生拖动，其余对象固定且不可选中；正式工作台保持原有交互。

演示总耗时按发送至完整回复的进度映射为 0–12 秒；每条工具记录的开始、返回时间使用同一时间轴。真实进度组件通过可选的 clockNow 接收演示时钟，摘要和展开后的单条记录均停止墙上时钟计时，暂停、倒回、跳步、重播保持一致。正式 Agent 未传入该参数时继续使用真实时间。

滚动可正向或倒回查看，也可用底部步骤跳转。系统启用减少动态效果时，使用步骤按钮切换。
