# 右侧聊天区：assistant-ui 接入

## 边界

- `useExternalStoreRuntime` 只投影宿主 `AgentChatMessage[]`；dashboard 仍负责 Agent 的 NDJSON 流、会话、画板和课件保存。
- 没有使用 assistant-cloud，也没有将工具重新注册为前端执行器。安装包的间接依赖不代表启用了云服务。
- 维持三栏布局、原有 Agent 选择和 GeoGebra 实例；不开放分支、编辑历史、重新生成或停止任务。
- `conversationId` 将输入草稿限定在当前课件；课件切换时重建聊天运行时，消息真源仍在宿主。

## 展示与输入

- 助手正文使用 Markdown、GFM 表格和 KaTeX，支持美元及转义括号数学分隔符；代码、宽表格和块公式在本区域内滚动。
- HTML 不执行，Markdown 远程图片不自动加载；题目附件通过原有图片预览展示。
- 图片本地读取为 data URL，沿用现有附件格式；上限 4 张、每张 6 MiB，PNG/JPEG/WebP/GIF。仅上传图片时补充默认题目指令，兼容当前接口的非空文本要求。
- 切换到不支持图片的 Agent 后，保留可移除附件并阻止发送，不静默丢图。
- 禁止发送与任务运行是两种状态：保存冲突时仍可编辑输入，不假装 Agent 正在生成。
- 工具步骤默认收起，仅展示实际活动元数据；“已返回”不等于构造检查通过。

## 执行过程与本轮结果

- 运行时只突出实际正在进行的工具活动；并行调用取最近开始且仍运行的一项，不补出尚未发生的阶段。
- 展开后按实际顺序展示“读取画板 / 更新构造 / 提交构造并检查”等活动和返回状态，内部工具名仅作为悬停提示；中断、工具返回错误和结果未确认分别保留。
- 构造相关回复结束后显示简短的“本轮结果”。指令数量只表示记录数量，不声称全部执行成功。
- 图形检查只读取已有 `auditResult`，列出缺失或数值未定义的对象；前三项直接可见，更多问题可展开。检查降级时提示信息不完整。
- 没有对象检查数据时显示“未检查”。无问题只表示未发现对象缺失或数值异常，不表示数学正确性已经验证。纯文字回复不附加图形检查块。
- 当前 Agent 流只保存工具活动元数据，没有自动从原始工具输出生成对象检查结果；因此新构造在没有 `auditResult` 的情况下显示“未检查”。此次调整不改变事件协议、工具执行或课件存储格式。

## 会话索引

- 消息区右侧的窄轨道按用户提问建立刻度；系统消息、助手正文和工具活动不增加刻度。少于两轮或没有滚动内容时隐藏。
- 悬停或键盘聚焦显示题目原文摘要和图片数量，不调用模型生成标题。点击定位到题目开头；当前阅读轮次的刻度加深。
- 刻度支持上下方向键、Home / End 和 Enter；轮次再多也只占消息区高度，预览保持在聊天面板内，不盖住输入框。
- 索引定位时暂停自动跟随，流式回复不会拉走阅读位置；“回到最新”或主动发送新题恢复跟随。减少动态效果设置下即时定位。
- 索引属于当前课件的临时展示状态，不改聊天记录、画板和课件保存格式。
