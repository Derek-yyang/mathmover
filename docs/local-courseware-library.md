# 本地课件库

未发送的输入草稿（文字和题图）按课件保留在当前工作台页面的内存中，切换课件后可恢复；不写入浏览器 localStorage 或课件数据库。发送或清空输入后移除对应草稿，删除课件会清理草稿，新建课件从空白输入开始。刷新或关闭页面会清空这些未发送的草稿。

正式课件由本机 daemon 管理，浏览器只负责编辑与展示。关闭浏览器、换浏览器或更新安装目录不会清空课件。此功能需要 **Node.js 24 或更新版本**（使用原生 `node:sqlite`）。

## 目录

默认目录与软件安装位置分离：

- Windows：`%LOCALAPPDATA%\MathMover`。
- macOS：`~/Library/Application Support/MathMover`。
- Linux：`$XDG_DATA_HOME/MathMover`，未设置时为 `~/.local/share/MathMover`。

```text
MathMover/
  library.sqlite           课件标题、对话、构造账本、版本与归档标记
  library.sqlite-wal/shm   SQLite 运行期间的辅助文件，不要手动删除
  coursewares/<id>/        按内容哈希存放不可变 .ggb 快照
  assets/                  题目原图，多个版本共用相同图片
  backups/<备份名>/        数据库及其引用的全部资源；complete.json 表示完成
  windows/<windowId>/      指定窗口的 Agent 工作文件
  .local-access-token     本机进程访问令牌，不要公开、上传或复制到网页
```

归档在 SQLite 中标记，保留快照、图片和历史版本。普通保存不会自动裁剪历史版本；频繁编辑、长期动画会增加版本数量和磁盘占用。永久删除会移除该课件及全部历史版本，并清理对应快照和不再被其他课件或历史版本引用的图片。

数据库升级到 schema 2 时，旧回收站记录会迁入归档，避免升级时丢失内容；原 `deleted_at` 字段和回收站恢复接口被移除。旧版预留的空 `trash/` 目录不再使用。

## 启动和自定义位置

开发环境启动 daemon（仓库根目录）：

```powershell
node --experimental-strip-types packages/daemon/src/cli.ts --no-mcp --ws-port 8787 --http-port 8788
```

在 `math-mover-next` 启动前端：`npm run dev`。必须同时启动 daemon，旧版 daemon 不提供课件接口，需要重启升级。不要在 Agent 任务执行期间重启。

自定义数据目录时，给 **daemon 和 Next 服务设置同一个** `MATHMOVER_DATA_DIR`。例如分别在两个启动终端设置：

```powershell
$env:MATHMOVER_DATA_DIR = 'D:\MathMoverData'
```

daemon 也支持 `--data-dir`，但 Next 仍需设置对应环境变量。修改目录不会自动迁移旧文件。未来安装器/桌面启动器应统一设置目录及两个服务的环境，并仅绑定回环地址；不要把带有本地文件权限的工作台作为公开 Web 服务部署。

## 保存和恢复

- 编辑后约一秒开始合并保存；聊天流有变化时持续保存，并非每个字符写一次。
- 首次发消息前先保存题目和图片；保存失败不会启动该轮 Agent。
- Agent 执行期间复用上一份已确认的画板检查点；任务结束后保存真实 .ggb 状态。对话与进度可能比画板检查点更新。
- `.ggb` 包含手工拖动、数值、样式等实际状态。构造账本同时保留，但不能用重放指令代替完整恢复。
- 保存成功后不常驻状态文字。一次实际保存超过 1 秒才显示“保存中…”，不包含修改后的自动保存等待或排队时间；成功后隐藏，失败保留错误和重试入口。浏览器刷新恢复 URL 对应课件，侧栏从本地库读取。
- 切换课件先保存当前编辑。快速切换的恢复操作串行执行。Agent 运行时禁止在当前页切换课件；点击“新建课件”会在新标签页打开独立的空白画板，旧任务继续在原标签页执行。空闲时仍在当前页新建。展开和收起侧栏的入口采用相同行为。
- 异常关闭后恢复最后提交的版本，不保证最后一秒或执行到一半的构造全部保留。中断的 Agent 任务会标记为中断，不自动重跑。

## 写入与窗口隔离

资源先通过临时文件写入、刷新，再移入不可变哈希路径；验证 GGB ZIP 目录、构造 XML 与 CRC，数据库事务最后提交资源引用。读取还会校验资源 SHA-256。失败不会覆盖上一份快照，可能留下未引用文件。

SQLite 使用 WAL、FULL 同步与版本号乐观锁。多窗口提交过期版本返回 409，保留本窗口未保存内容，不自动覆盖其他窗口。冲突时先导出画板/复制需要保留的对话，再“重新加载本地版本”。新一轮 Agent 会被阻止，避免在冲突基础上继续执行。

工作台窗口通过同源接口领取一次性绑定票据，Agent 的 MCP 子进程携带该窗口 ID。指定窗口断开时明确报错，不回退到最新连接的其他画板。兼容旧 CLI 的不指定窗口工具调用仍是旧全局行为，不用于工作台新对话。

## 归档与永久删除

- 侧栏只展示最近课件，课件菜单保留“归档”操作。“设置 → 归档课件”可以搜索、打开、重命名、取消归档或永久删除课件，也支持批量删除。打开归档课件会关闭设置并恢复对话和完整画板；继续编辑仍保持归档状态，只有取消归档才重新出现在最近列表。
- 归档和取消归档使用版本号乐观锁，不覆盖其他窗口更新；Agent 执行期间禁止列表修改。
- 删除确认后永久移除课件、对话和画板历史，没有回收站或恢复按钮。删除当前课件会回到空白画板。
- 前端删除前会确认 daemon 支持永久删除；旧服务未重启时提示升级，不调用旧版的软删除接口。
- 数据库仅保留已删除 ID，用于拒绝其他窗口的延迟保存，不保留可恢复的课件内容。
- 文件清理失败会记录待清理路径，在下次删除或 daemon 启动时重试；数据库中的课件已删除。共享图片仍被其他课件或历史版本引用时会保留。

## 备份

“设置 → 数据与存储”显示实际目录，提供备份。备份使用 SQLite 原生备份 API，再复制备份数据库所引用的不可变资源，最后写 `complete.json`。未完成的备份不应作为恢复来源。备份进行时，当前 daemon 会延后删除资源文件，直到备份复制完成；课件列表中的删除仍立即生效。既有完整备份是独立副本，删除课件不会修改它们。

不要只复制正在运行的 `library.sqlite`，也不要删除 WAL/SHM。恢复整个备份的第一版操作方式是：停止两个服务，保留现有数据目录，复制完整备份到一个**新的**数据目录，将两个服务的 `MATHMOVER_DATA_DIR` 指向它并启动；daemon 会创建新的访问令牌。不要覆盖原目录，便于回退。当前尚无整库恢复向导或可视化版本回滚页。

这只是本地备份，不防止整块硬盘损坏；重要课件应把完整备份额外复制到另一个设备。

## 验证范围

存储/HTTP 测试覆盖重开数据库、冲突拒绝、写入失败、归档/取消归档、旧回收站迁入归档、永久删除全部版本、拒绝删除后的延迟保存、共享图片保留、清理失败重试、旧回收站接口拒绝、损坏检测、未来数据库版本拒绝、备份及删除并发、指定窗口路由与断开，以及资源写入后/DB 提交前强杀写入进程。

已有浏览器验收使用真实 GeoGebra 与本地文件库，验证题目/回复保存、题目原图落盘及刷新加载、拖动后的点坐标、滑块修改及刷新恢复、重命名后继续保存和备份。双窗口真实画板验收确认：仅打开课件不额外写入版本；第一窗口保存后，第二窗口旧版本提交返回 409，其编辑仍留在页面；冲突时发送禁用；重新加载恢复的是第一窗口成功保存的数据，不自动调用 Agent。

本轮 `scripts/verify-courseware-thread-list.mjs` 使用真实 GeoGebra 和隔离 API 替身，验证归档列表、归档课件恢复对话和完整画板、继续编辑、取消归档、失败重试、单项和批量删除、当前课件删除后清空画板；它不写真实课件库。数据库与 HTTP 行为另由 daemon 测试验证。实际断电、物理磁盘满、安装器升级迁移与跨平台打包仍需后续验收。
